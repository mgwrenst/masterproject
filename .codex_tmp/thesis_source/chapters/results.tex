\section{Overview of Experiments}


\subsection{Experimental Setup}

As presented in the Methodology chapter, this study used a benchmark framework to conduct the experiments. A Large Language Model (LLM) was use to generated a MongoDB query for each benchmark question using natural language in Norwegian. A database description was sent along with the query input. The generated query was then executed against a MongoDB database and the retrieved results were compared against a corresponding gold-standard query results. 

The evaluation focused on the relevance of the retrieved information. This was measured using precision, recall and F1-score. If a query failed to execute due to syntax or runtime errors, it was treated as unsuccessful.
