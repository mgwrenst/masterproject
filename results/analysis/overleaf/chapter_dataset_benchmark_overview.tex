\begin{table}[htbp]

\small
\caption{Database and schema-description variants evaluated in the benchmark.}
\label{tab:schema-variant-overview}
\begin{tabular}{lp{0.63\linewidth}}
\toprule
Variant & Description \\
\midrule
Flat database & Separate MongoDB collections resembling relational tables: \texttt{selskap}, \texttt{personer}, \texttt{politikere}, \texttt{eierskap} and \texttt{aksjeeiebok}. Cross-collection questions usually require matching on organisation number, name, birth date or UUID. \\
Structured database & Document-oriented MongoDB representation where \texttt{selskap} and \texttt{personer} contain embedded relationship summaries in addition to separate collections for detailed records. \\
Naive schema description & Natural-language description of each collection and its intended use. \\
Technical schema description & Field-level schema with types, nested paths and selected example values. \\
\bottomrule
\end{tabular}
\end{table}
